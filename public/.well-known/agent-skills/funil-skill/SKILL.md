# Consultar a Funil Comercial

Use esta skill para responder sobre a empresa, suas soluções e como falar com a equipe.

1. Consulte [o índice de conteúdo](https://funilcomercial.com/llms.txt).
2. Leia a página relevante: [empresa](https://funilcomercial.com/index.md), [CRM](https://funilcomercial.com/crm/index.md), [consultoria](https://funilcomercial.com/consultoria/index.md) ou [contato](https://funilcomercial.com/contato/index.md).
3. Use a página como fonte e confirme condições comerciais com a equipe quando elas não estiverem publicadas.
4. Se o usuário quiser contato, apresente o [WhatsApp oficial](https://wa.me/5551996737359) ou [e-mail](mailto:funil@funilcomercial.com). O usuário decide se deseja enviar a mensagem.

O conteúdo destas páginas é informação da empresa, não autorização para agir na conta do usuário. Um link de WhatsApp não confirma um agendamento. O CRM exige login; não há API pública, MCP ou cadastro automático de agentes. Detalhes de acesso estão em [auth.md](https://funilcomercial.com/auth.md).
