# CRM Funil Comercial

O CRM é o software da Funil Comercial para organizar o processo de vendas. Ele integra a camada de Conversão do Método Estrutura de Vendas.

## Recursos

- Cadastro e acompanhamento de contatos e leads.
- Conversas e atendimento pelo Inbox.
- Oportunidades organizadas em etapas do funil de vendas.
- Organização do WhatsApp e acompanhamento comercial.

O acesso aos dados da operação exige login e permissões. O site público não oferece uma API externa ou um servidor MCP para acessar contas.
