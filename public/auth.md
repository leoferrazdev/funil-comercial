# Acesso de agentes — Funil Comercial

## Conteúdo público

O site institucional pode ser consultado sem autenticação. Consulte [llms.txt](https://funilcomercial.com/llms.txt) e o [catálogo de recursos públicos](https://funilcomercial.com/.well-known/ai-catalog.json).

As páginas que oferecem Markdown aceitam `Accept: text/markdown` ou o caminho `/index.md` relativo à página. As páginas principais contam com resumos estáticos mesmo quando o prerender não está disponível na hospedagem.

## Contas e dados privados

O CRM usa login e permissões por usuário. A entrada é [a página de login](https://funilcomercial.com/login). Não há cadastro automático de agentes, servidor OAuth para terceiros, escopos de API pública ou servidor MCP neste domínio.

A descoberta Poppy anuncia apenas navegação pública, sem autenticação delegada ou sessões compartilhadas. A ausência de `authorization_servers` nos metadados indica que o site público não tem um emissor OAuth para agentes.
